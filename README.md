# ⚡ FlowDo (플로우두) - 스마트 일정 & 타임블록 플래너

> **자연어로 빠르게 캡처하고, 24시간 타임블록과 주간·월간 달력으로 완벽하게 계획하는 반응형 Local-First 스마트 Todo 웹 앱**

---

## 🌟 FlowDo 소개
**FlowDo**는 복잡한 입력 양식 없이 일상적인 대화체로 할 일을 적으면 시간, 날짜, 우선순위, 카테고리를 알아서 분석해 주는 똑똑한 생산성 도구입니다.  
오프라인에서도 실시간으로 데이터가 저장되는 **Local-First** 아키텍처를 채택하여 로그인 없이 즉시 사용하실 수 있습니다.

---

## 🚀 핵심 주요 기능

### 1. ⚡ 초저지연 자연어 퀵 캡처 (NLP Quick Capture)
- **자연어 파싱**: "내일 오전 9시 자동차 검사 #업무 !p1", "6시 가족 외식" 등 일상 구어체를 입력창에 적기만 하면 날짜, 시간블록, 우선순위, 카테고리를 자동으로 추출합니다.
- **카테고리 스마트 자동 분류**: 키워드(보고서, 회의, 공부, 외식, 병원 등)를 분석하여 `🏢 업무`, `👤 개인`, `📚 공부` 카테고리로 자동 분류합니다.
- **실시간 미리보기 칩**: 타이핑하는 순간 감지된 날짜, 시간, 카테고리 뱃지를 즉시 시각화해 줍니다.
- **전역 단축키**: 어디서든 `Cmd + K` / `Ctrl + K`를 누르면 입력창으로 즉시 포커스됩니다.

### 2. 📅 4가지 멀티 일정 뷰 모드
상단 네비게이션을 통해 언제든지 상황에 맞는 뷰를 전환할 수 있습니다:
- **리스트 뷰**: 해야 할 일을 체크리스트와 24시간 타임라인 사이드바로 한눈에 확인하는 집중형 뷰.
- **일간 타임라인 뷰**: 06:00부터 24:00까지 시간대별로 할 일을 시각적 블록으로 배치하고 드래그 & 클릭으로 시간 배정.
- **7일 주간 플래너 뷰**: 월요일부터 일요일까지 7일간의 주간 일정을 한눈에 조망하고 요일별 빠른 일정 추가 지원.
- **월간 일정 캘린더 뷰**: 7열 달력 그리드를 통해 한 달 전체의 일정을 확인하고 일자별 상세 태스크 조회.

### 3. 🔴 네이버 달력 공식 법정공휴일/대체공휴일 실시간 연동
- 대한민국 천문연구원(KASI) 및 네이버 달력 표준 2024~2028년 법정공휴일·대체공휴일 데이터셋 완벽 내장.
- 공휴일 및 일요일은 붉은색 날짜(`text-rose-500`)와 함께 공식 명칭(예: `추석`, `설날`, `3ㆍ1절`, `대체공휴일`)이 표시됩니다.

### 4. 🧭 과거나 미래 날짜 자유 선택 (Date Warp)
- 상단 헤더의 날짜 배지를 클릭하면 미니 캘린더 팝오버가 열려 **과거 또는 미래 어떤 날짜든 자유롭게 탐색**할 수 있습니다.
- 일간, 주간, 월간 달력의 어떤 날짜 셀을 클릭해도 전역 선택 날짜가 실시간 동기화됩니다.

### 5. 📊 오늘의 달성률 시각화 대시보드
- 오늘 완료율 프로그레스 바 (`X/Y completed (Z%)`).
- 카테고리별 진행 현황 그리드 (`Work`, `Personal`, `Study`).
- 원클릭 카테고리 알약 필터 탭 지원.

### 6. 📱 실제 스마트폰(390px) 화면 시뮬레이터 & 터치 제스처 스크롤
- 헤더 좌측의 **`[💻 Web/App v1.2 •]`** 버튼을 클릭하면 실제 iPhone/Galaxy 스마트폰 규격(390 × 844px) 목업 화면으로 즉시 전환됩니다.
- **마우스 드래그 터치 제스처**: 데스크톱에서도 화면을 마우스로 잡고 쓸어올려 손가락 터치와 같은 스와이프 스크롤을 체험할 수 있습니다.
- **`[↗️ 390px 독립 팝업창으로 열기]`**: 클릭 시 별도의 390px 브라우저 창이 열려 브라우저 개발자 도구의 터치 에뮬레이션을 자유롭게 사용하실 수 있습니다.

### 7. 🌓 다크 모드 & 라이트 모드 (Dark / Light Theme)
- 상단 우측 ☀️/🌙 버튼으로 눈이 편안한 다크 모드와 산뜻한 라이트 모드를 자유롭게 전환할 수 있습니다.
- 설정은 로컬 스토리지에 영구 저장됩니다.

### 8. 🔒 오프라인 로컬 퍼스트(Local-First) & 중복 생성 4중 방어
- 서버 장애나 인터넷 연결 끊김 걱정 없이 모든 데이터가 브라우저에 안전하게 보관됩니다.
- 한글 IME 조합 완료 시점, 키보드 더블 엔터, 빠른 연타로 인한 일정 중복 생성을 4중으로 완벽 차단합니다.

| 구분 | 기술 |
| :--- | :--- |

| **Language** | TypeScript |
| **Styling** | Tailwind CSS, PostCSS, Autoprefixer |

## 💻 설치 및 로컬 실행 방법

### 1. 요구사항
- Node.js 18.17 이상
- npm 또는 yarn, pnpm

### 2. 패키지 설치
```bash
npm install
```

### 3. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 [http://localhost:3000](http://localhost:3000) 접속하여 앱을 확인합니다.

### 4. 프로덕션 빌드 및 실행
```bash
npm run build
npm start
```
